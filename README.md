# AFTERZERO — Game 01: The First Cycle

A first-person narrative puzzle game for **Android and iOS** (also runs on PC/Mac), built in **Unity 6 with URP**.
Arin Vale arrives in Veyra on the last train, carrying a letter dated tomorrow. Veyra repeats a catastrophe every
night, and Arin learns to move between its three coexisting states (**PAST, PRESENT, FUTURE**) to find out why.

- **Content:** Prologue, 8 levels, 3 interludes and an Epilogue with two endings. There are also 24 hidden memory
  fragments. The target play time is about 2 hours; it hasn't been playtested yet.
- **Story:** see [`Docs/STORY.md`](Docs/STORY.md). The level design source is
  [`Docs/GAME_01_THE_FIRST_CYCLE_DETAILED_LEVELS.docx`](Docs/GAME_01_THE_FIRST_CYCLE_DETAILED_LEVELS.docx).
- **Generated levels:** every level is generated by code, so a single menu click rebuilds the whole game.

> **Status — please read.** I wrote all the code in a cloud session with no Unity Editor. It was compile-checked
> against Unity's reference assemblies and package API stubs, but it has **never been opened, played or built in
> Unity**. The first run will likely turn up issues: object placement, scale, pacing, maybe a few API mismatches
> with your exact Unity version. Those are quick to fix from inside Unity, and the Unity MCP bridge (below) lets
> Claude Code fix them with you. The geometry is stylised "greybox plus lighting": primitives, URP materials,
> neon, holograms and particles. Swap in real models and textures to reach a commercial look.

## 1. Open the project
1. Install **Unity Hub** and **Unity 6 LTS (6000.0.x)**. Add these modules: **Android Build Support** (with
   OpenJDK and Android SDK & NDK), and **iOS Build Support** if you have a Mac.
2. In Unity Hub, choose **Add → Add project from disk** and select this folder, then open it with Unity 6.
3. On first open:
   - Packages install automatically, including **MCP for Unity**.
   - If Unity asks to enable the new **Input System** backend, click **Yes**. The editor restarts.
   - AfterZero sets up URP high-fidelity graphics automatically. To re-apply it later, use
     **AfterZero ▸ Setup ▸ Apply High-Fidelity Graphics**.
4. Run **AfterZero ▸ Build All Levels**. This generates the main menu, Prologue, all 8 levels and the Epilogue, and
   adds them to Build Settings.
5. Run **AfterZero ▸ Validate Levels** to check each level against the design doc's QA checklist.
6. Open `Assets/AfterZero/Scenes/AZ_MainMenu.unity` and press **Play**.

## 2. Build for phones
| Target | Menu | Output |
|---|---|---|
| Test on an Android phone | **AfterZero ▸ Mobile ▸ Build Android APK** | `Builds/Android/AfterZero_FirstCycle.apk`. Copy it to the phone, or run `adb install`. |
| Google Play | **AfterZero ▸ Mobile ▸ Build Android App Bundle** | `.aab` file. Set up signing in *Player Settings ▸ Publishing Settings* first. |
| iPhone / iPad | **AfterZero ▸ Mobile ▸ Export iOS Xcode Project** | `Builds/iOS/`. Open it in Xcode on a Mac, set your Apple Team, then Run or Archive. |

- **Bundle id:** `com.skandax.afterzero.firstcycle`. Change it in `Assets/AfterZero/Editor/AZMobileBuild.cs`.
- **Builds:** IL2CPP ARM64, Android 8.0+ / iOS 15+, landscape only.
- **Mobile graphics profile:** applied automatically on phones. It targets 60 fps with render scale 0.8, shorter
  shadows, fewer particles and cheaper light probes. Tune it in `Scripts/Mobile/MobileOptimizer.cs`.
- **Testing the phone UI in the editor:** turn on **AfterZero ▸ Mobile ▸ Simulate Touch Controls in Editor**, or use
  Unity's **Device Simulator** (*Window ▸ General ▸ Device Simulator*).

## 4. Using Claude with Unity MCP
The project includes **MCP for Unity** (`com.coplaydev.unity-mcp`). To connect it:
1. Install **Python 3.10+** and **uv**.
2. In Unity, open **Window ▸ MCP for Unity ▸ Configure All Detected Clients** and choose Claude Code.
3. Run `claude` in this folder and check `/mcp`. Claude reads `CLAUDE.md` to learn how the project works.
4. Example prompts:
   - *"Run AfterZero/Build All Levels, then open AZ_L01 and play it. Fix any Console errors."*
   - *"In Level05Builder, make the flood rise slower and add more lanterns in the Past."*
   - *"Build the Android APK and tell me the size."*

## 5. How it's built
| Area | Where |
|---|---|
| State system (Past/Present/Future, echoes) | `Scripts/Core/TemporalStateManager.cs`, `TemporalPresence.cs` |
| Cause and effect, the recurrence loop | `Scripts/Core/WorldState.cs`, `LoopManager.cs`, `Scripts/Puzzles/LoopScheduledEvent.cs`, `Interaction/FlagReactor.cs` |
| Story flow, objectives, endings | `Scripts/Core/LevelDirector.cs`, `GameFlow.cs`, `EpilogueSequence.cs`, `Interaction/MemoryFragment.cs` |
| Puzzles and hazards | `Scripts/Puzzles/*` (alignment, sequences, water, telegraphed hazards, stealth machine, crisis timer, evacuation) |
| NPC life (routines, reactions, changed states) | `Scripts/NPC/NPCMotor.cs`, `NPCPersona.cs` |
| Visuals (per-state colour grades, time ripple, holograms) | `Scripts/Visuals/TemporalVisuals.cs`, `Shaders/Hologram.shader` |
| Audio (fully procedural; replace by dropping clips in `Resources/AfterZero/Audio/`) | `Scripts/Audio/*` |
| Touch controls and mobile performance | `Scripts/Mobile/*` |
| Level generators | `Editor/Levels/Level0NBuilder*.cs`, `Editor/AZStoryScenes.cs`, toolkit `Editor/AZKit.cs` |

## 6. Making it look like a shipped game
- **Art:** replace the greybox meshes with real assets (Asset Store, Synty or custom). Keep the gameplay components
  in place. Builders refer to materials by key in `AZMaterials.cs`, so swapping a material updates every level.
- **Voice and music:** add recorded dialogue and music; subtitles are already in place.
- **Mobile:** after the art pass, profile on a mid-range phone. The main costs will be draw calls and the number of
  point lights.
